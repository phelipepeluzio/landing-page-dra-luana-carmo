# Landing page – Dra. Luana Costa do Carmo

Site institucional desenvolvido para uma cirurgiã-dentista em Madureira, Rio de Janeiro.

🔗 **Site no ar:** https://draluanacarmo.draluana.workers.dev/

## Sobre o projeto

Página única com apresentação da profissional, serviços (implantes, facetas, prótese protocolo, endodontia e harmonização facial), depoimento em vídeo, localização e contato para agendamento.

## Destaques técnicos

- **Performance:** imagens otimizadas de cerca de 28 MB para cerca de 3 MB, para carregamento rápido no celular
- **SEO e compartilhamento:** meta tags Open Graph para prévia em redes sociais e `robots.txt` liberando a indexação
- **Ícones** para aba do navegador e atalho na tela inicial do celular
- **Hospedagem** em Cloudflare Workers, com entrega de arquivos estáticos

## Tecnologias

HTML · CSS · JavaScript · Cloudflare Workers
